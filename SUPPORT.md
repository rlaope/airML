# Getting help with airML

## Documentation

- **Quickstart**: see [README.md](README.md)
- **Full guide**: build locally with `cd book && mdbook build`, or visit the published site at the URL listed in `book/book.toml`
- **API reference**: https://docs.rs/airml

## Question or feature request

- **General questions**: open a GitHub Discussion (Q&A category).
- **Feature requests**: open an issue using the "Feature request" template.
- **Bug reports**: open an issue using the "Bug report" template.

## Security issues

See [SECURITY.md](SECURITY.md). Do not file security vulnerabilities as public issues.

## Commercial support

We do not offer commercial support at this time. For paid integration help, please reach out via GitHub Discussions.
